Ultra-responsive Billing & Cart Engine

Our POS checkout interface lets cashiers execute payments, scan items, search customer credit details, and print receipts without touching a mouse.

  • ⚡ F1 key shortcut clears current sale state instantly for the next customer.
  • 🎒 Loyalty Wallet allows customers to redeem earned points directly on invoice checkout.

FEFO & FIFO Batch tracking

Maintain optimal freshness and mitigate waste of perishable items. Zetamart automatically drains stock from the oldest active batch.

  • 📅 Auto Expiry Warnings alert managers when batches are nearing their sell-by dates.
  • 🔍 Stock Audits allow staff to log counted quantity and reconcile stock discrepancies.
  • 📈 Ledger Records log detailed audit histories for every stock delta.

Live Role Permissions Synchronization

Zero risk of unauthorized inventory adjustments or revenue views. All layout navigation drawer options sync live with user roles.

  • 🚫 Menu Hiding: If a cashier's read reports permission is unselected, the "Reports" option vanishes.
  • 🔐 Endpoint Guards: Block exports, ledger logs, and analytics calls on the backend API layer.
  • 🔄 Real-time update: Active sessions instantly reload navigation links when an admin updates roles.
